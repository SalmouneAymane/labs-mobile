# Prompt

Create a simple, engaging presentation in French that introduces the 2TUP software development method to students.

Use the attached `schema.png` to guide the process diagram. Explain that the functional and technical tracks can move forward in parallel, then come together for design, coding, testing, and final acceptance. In plain language, cover what each track does and why the prototype is useful.

Keep the presentation short and easy to follow—around 6 or 7 slides is fine. Use clear titles, brief explanations, and helpful visuals instead of crowded slides. A clean, modern design would work well. Finish with a quick summary of the main idea.

If you create it as a web presentation, make sure the slides are easy to navigate with buttons or the keyboard, and that it works on different screen sizes.
