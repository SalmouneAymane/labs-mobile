# Copie du dossier `live`

Cette arborescence reprend le projet `lab-erreur-js/live` du [dépôt source](https://github.com/mesbahimohammedyassirsolicode-star/lab/tree/main/lab-erreur-js/live). Le JavaScript contient volontairement les erreurs utilisées comme point de départ pour l'exercice; ce n'est pas la version corrigée.

## Lancer l'exemple

Depuis la racine du dépôt courant :

```powershell
php -S localhost:8000 -t .\JavaScript-Errors\live
```

Ouvrir `http://localhost:8000/frontend/`. L'URL API du script est `http://localhost:8000/backend/api/api.php`.

Les URL, identifiants et problèmes d'intégration présents dans la copie font partie de l'exercice de débogage. Utiliser la version pédagogique [`../prjt/`](../prjt/) pour les reproductions isolées et les corrections guidées.
