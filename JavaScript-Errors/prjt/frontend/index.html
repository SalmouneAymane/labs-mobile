01DOM · TypeError

Formulaire introuvable

Cannot read properties of null (reading 'addEventListener')

Le sélecteur ne trouve aucun élément. Vérifiez l'identifiant et l'ordre de chargement; si le formulaire est optionnel, protégez l'écouteur avec un contrôle.

// Erreur
document.getElementById("form-commentaire")
  .addEventListener("submit", handleSubmit);

// Correction si le formulaire est optionnel
const form = document.getElementById("form-commentaire");
if (form) form.addEventListener("submit", handleSubmit);
Choisissez une action pour voir le résultat.
02JSON · SyntaxError

Réponse HTML lue comme JSON

Unexpected token '<', "<!DOCTYPE..." is not valid JSON

Le serveur a renvoyé une page HTML (souvent une erreur PHP), mais le client essaie de la parser comme du JSON.

// Correction côté client
const type = response.headers.get("content-type") || "";
if (!type.includes("application/json")) {
  throw new Error("Le serveur n'a pas renvoyé du JSON");
}
const data = await response.json();

03Tableau · TypeError

Mauvaise forme de données

posts.forEach is not a function

Le code attend un tableau; l'API a renvoyé un objet qui contient sa liste dans data.

// Correction : valider puis sélectionner la liste
const posts = Array.isArray(payload)
  ? payload
  : payload.data;

if (!Array.isArray(posts)) {
  throw new TypeError("Liste invalide");
}
posts.forEach(renderPost);

04Réseau · TypeError

Requête impossible

TypeError: Failed to fetch

Le serveur est arrêté, l'URL est incorrecte, ou le navigateur bloque la requête (par exemple, CORS).

// Correction : traiter explicitement le rejet
try {
  const response = await fetch(apiUrl);
  if (!response.ok) throw new Error(`HTTP ${response.status}`);
  showData(await response.json());
} catch (error) {
  showNetworkMessage("API indisponible");
}

05Portée · ReferenceError

Fonction non définie

ReferenceError: displayArticles is not defined

La fonction appelée n'existe pas dans cette portée ou n'a pas été chargée au moment de l'appel.

// Déclarer la fonction et ses dépendances avant l'appel
const articleList = document.querySelector("#article-list");
function displayArticles(articles) {
  articleList.replaceChildren(...articles.map((article) => {
    const item = document.createElement("li");
    item.textContent = article.title;
    return item;
  }));
}
displayArticles([{ title: "Un article" }]);
