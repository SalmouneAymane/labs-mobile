Lab · Développement Web

Découvrir Laravel

Comprendre le framework PHP qui aide à construire des applications Web structurées, maintenables et rapidement testables.

Objectif du lab : rechercher et comprendre ce qu’est Laravel, son rôle, ses avantages et son utilisation dans le développement d’applications Web.

1. Qu’est-ce que Laravel ?

Laravel est un framework open source écrit en PHP. Un framework fournit une structure et des outils réutilisables : au lieu de tout construire à partir de zéro, le développeur s’appuie sur des conventions et des composants communs.

Laravel est principalement utilisé pour développer la partie serveur d’applications Web : sites dynamiques, API et applications métier. Il ne remplace pas PHP ; il organise et accélère son utilisation.

2. Quel est son rôle ?

Une application Web reçoit des requêtes, applique des règles métier, lit ou modifie des données, puis renvoie une réponse. Laravel fournit des outils pour organiser ces étapes, notamment avec une architecture de type MVC :

  • Model (modèle) : représente et manipule les données, souvent avec Eloquent, l’ORM de Laravel.
  • View (vue) : présente l’information à l’utilisateur, par exemple avec le moteur de templates Blade.
  • Controller (contrôleur) : reçoit la requête et coordonne le traitement.
Requête HTTP→ Route→ Contrôleur→ Modèle / données→ Réponse

Une route associe une URL et une méthode HTTP à un traitement. Le contrôleur peut appeler un modèle, puis retourner une vue HTML ou des données JSON.

3. Outils et avantages

  • Routage et middleware : définissent les URL et les traitements transversaux, comme l’authentification.
  • Eloquent ORM : facilite le travail avec les bases de données via des modèles PHP.
  • Migrations : décrivent et versionnent les changements de structure de la base de données.
  • Blade : permet de créer des pages HTML à partir de vues réutilisables.
  • Écosystème : propose des outils pour les tests, les files d’attente, la validation, le cache et bien plus.

Ces outils favorisent la productivité, la cohérence du code et la maintenabilité. Ils ne garantissent pas automatiquement une application de qualité : le développeur doit toujours concevoir, sécuriser et tester son code.

4. À quoi ressemble une route ?

Dans une application Laravel, les routes Web sont généralement définies dans routes/web.php. Voici une route simple qui renvoie une réponse :

use Illuminate\Support\Facades\Route;

Route::get('/bonjour', function () {
    return 'Bonjour !';
});

Lorsqu’un navigateur envoie une requête GET /bonjour, Laravel trouve cette route et renvoie le texte. Dans une application plus complète, la route appelle souvent un contrôleur plutôt qu’une fonction anonyme.

5. Quand utiliser Laravel ?

Laravel convient notamment aux sites et applications métier avec des utilisateurs, des formulaires, des données, des rôles ou des API. Il est souvent choisi lorsqu’une équipe veut s’appuyer sur PHP et un écosystème structuré.

À retenir : un framework apporte une base et des conventions, mais il faut apprendre PHP, le fonctionnement HTTP, les bases de données et les bonnes pratiques de sécurité pour l’utiliser correctement.

6. Activité de recherche

  1. Consultez la documentation officielle de Laravel et identifiez trois fonctionnalités.
  2. Expliquez avec vos propres mots le trajet d’une requête dans une application Laravel.
  3. Comparez Laravel à du PHP écrit sans framework : qu’est-ce qui devient plus simple, et qu’est-ce qui reste à la charge du développeur ?
  4. Présentez un exemple de site ou d’API qui pourrait être développé avec Laravel et justifiez votre choix.
